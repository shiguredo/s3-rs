# s3cli に --expected-size オプションを追加する

## 概要

cp サブコマンドに `--expected-size` オプションを追加する。

## 動作

- stdin やパイプからのストリームアップロード時にデータの期待サイズを指定する
- マルチパートアップロードのパートサイズ計算に使用する
- 指定しない場合はデフォルトのパートサイズを使用する

## 使用例

```bash
cat largefile.bin | s3cli cp - s3://bucket/key --expected-size 10737418240
```

## 備考

- クライアント側の機能であり S3 API には依存しない
- stdin からのアップロード (`-` をソースに指定) に対応する必要がある

## 解決方法

- cp コマンドでソースが `-` の場合に stdin から読み込んでアップロードする機能を追加した
- `--expected-size` オプションでバッファの事前確保を行う
- `calculate_part_size()` でデータサイズから最適なパートサイズを自動計算する
- tokio に `io-std` feature を追加した
